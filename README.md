# Bookstore Inventory and Analytics System

## 1. Project Title
Bookstore Inventory and Analytics System

## 2. Project Objective
The objective of this project is to develop a Python-based Bookstore Inventory and Analytics System.

This system helps bookstore owners manage books, update inventory, record sales, calculate revenue, analyse sales data and understand customer preferences through charts and reports.

## 3. Problem Statement
Bookstore owners need a system to manage their inventory, track book sales and understand sales performance.

This project provides a simple solution using Python programming, data analysis and data visualization.

## 4. Features and Functionalities

### 1. Inventory Management
- Add new books to inventory.
- Remove books from inventory.
- Update book quantities.
- Validate book prices and quantities.
- Display available books.

### 2. Bookstore Class (OOP)
The project uses a Bookstore class with the following methods:

- `add_book()` - Adds a new book.
- `update_inventory()` - Updates book stock.
- `record_sale()` - Records book sales and reduces stock.
- `generate_report()` - Displays inventory and sales reports.
- `show_charts()` - Displays sales charts.

### 3. Sales Analysis and Computations
Using NumPy and Pandas:

- Calculate total revenue.
- Calculate average book price.
- Find best-selling books.
- Analyse sales by genre and author.
- Calculate monthly sales growth.
- Read and manage CSV datasets.

### 4. Data Visualization
Using Matplotlib and Seaborn:

- Bar Chart - Total book sales by genre.
- Line Graph - Monthly sales trends.
- Pie Chart - Revenue share by book genre.
- Heatmap - Correlation between book prices and sales volumes.
